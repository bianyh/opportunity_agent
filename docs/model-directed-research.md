# 模型主导的研究流程

默认 `RESEARCH_AGENT_ENABLED=1`。真实 ResearchService 的问题理解和检索执行走 `model_agent.py`，不调用关键词 `parse_task`；旧规则流水线可显式设为 `0`，用于旧版兼容和对照测试。

## 职责

模型结合当前消息和近期对话输出完整研究事项、入学季、检索词、官网入口；收到搜索结果和官网链接后，为每个事项独立决定下一步读取/搜索或返回带原文的答案。

程序提供类型校验、官方域名/公开地址/HTTPS/重定向安全检查、robots 规则、预算、重复调用防护和引文校验。它不靠缩写正则决定搜索目标，也不会因为识别不出的项目而静默丢项。模型计划失败时明确记录规划失败，不退回规则解析器假装已完整理解。

研究上下文只传近期对话和摘要；画像、进度、计划等可修改状态仍不传给 Research。第一个目标缺学校时，只保留该事项的澄清，其余明确目标照常查询。最终状态逐项保留 `answered / needs_user / exhausted`，不会为了一个待澄清项发起无意义的全局重试。

## 工具与资料

- 公共 Bing RSS 搜索，跟随搜索提供方的重定向并过滤官方结果。返回标题/片段只作导航，不作答案证据。可配置的 `OFFICIAL_SEARCH_URL` 仍可并行提供额外候选。
- 模型可以提出官方 URL；网页读取器独立验证该 URL。模型也可以沿已读取网页中的真实链接前进。目录/主页使用简短正文和链接列表，证据页使用原文块。
- 每个研究事项独立、小上下文地调用模型，网络工具并行执行；单个事项的失败不取消其他事项。
- 正式资料库中的既有校验事实可直接命中。新读取的官网原文、链接和读取时间自动入库，无需人工审核；未过期的已保存原文可复用，仍由模型解释和引用。
- 规划模型可以查看已有的官方来源标题和地址，选择相关入口；这不是项目白名单，也不把历史对话答案当成事实。换学校不重置历史明确的入学季。
- 来源结论必须绑定已读取页的 `page_ref`、`block_id`、原文精确子串和该页的身份原文。程序检查出处和引文；页面适用性及语义由模型判断。模型结论以 source-bound findings 返回，不冒充通过原有 AdmissionFact 校验的结构化筛选字段。
- 年度官网只写月日时照常报告有用的月日，并标明原文未写适用年份；不能自动补成 2027 的 ISO 日期。显式入学季的结论另有本地原文入学季检查。

引文的表格换行/分隔符或重复转义可做纯布局修复，但词、数字、标点和顺序必须一致，最终保存的是实际原文子串。被拒绝的日期引文不能让“只提取到时区”的事项被标为完整回答。

## 网关与预算

沿用配置的 `gpt-6.1-sol`，没有切换网关或模型。默认研究模型使用 `low` 推理量。流式响应只在内部消费；完整 JSON 根对象通过 schema 校验后结束等待，不等兼容网关额外的结束帧。未完成的 JSON 从不执行工具。

可配置参数：

```dotenv
RESEARCH_AGENT_ENABLED=1
RESEARCH_AGENT_MODEL_TIMEOUT_SECONDS=110
RESEARCH_AGENT_REASONING_EFFORT=low
RESEARCH_AGENT_BUDGET_SECONDS=300
RESEARCH_AGENT_MAX_STEPS=5
```

另有每事项最多 8 个工具调用及总工具上限。预算只控制执行，不根据规则识别出的学校数缩掉模型识别的额外项目。外部模型延迟、502 和搜索覆盖不足仍会被记录，不承诺所有项目都能一次成功。

规划使用简短的 `PlanDraft` 线格式，再通过 schema 转为逐项状态；这是模型输出的格式校验，不是规则识别用户意图。导航决策与来源回答使用不同的短提示；初始深层招生页面按证据模式读取，只有主页才裁成导航模式。
